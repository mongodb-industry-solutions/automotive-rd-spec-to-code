Key Responsibility:

Protocol & Security Highlights

1. Stdio FastMCP Transport
Communication between the agent and MongoDB Atlas occurs over isolated process stdio (JSON-RPC 2.0). No public ports or unauthenticated HTTP endpoints are exposed.
2. Grounded Atlas Vector Search
Direct $vectorSearch queries match natural language prompts against verified ASPICE / ISO 26262 knowledge bases with Voyage-3.5 embeddings (1024d), preventing LLM hallucinations.
3. End-to-End Traceability
Every step is recorded in OpenTelemetry JSON schema: prompt tokens, MCP tool call arguments, vector relevance scores, C++ code generation, and test linkage.
